# agent_UVR-5
用于创建使用uvr5模型的流程化歌曲处理脚本
用法说明
注意：本程序使用win11平台，python 3.12.9开发，显卡生产商为英伟达，cuda版本为12.1，amd 平台暂未尝试。
推荐使用 venv 虚拟环境
***
python -m venv my_venv
my_venv\Scripts\activate.bat
***
部署好虚拟环境并且成功启动之后，在虚拟环境中完成依赖的下载
***
pip install -r requirements.txt
***
!!!注意，此处默认下载cpu版本的torch，如需显卡加速，请根据显卡厂商选择加速驱动
完成依赖项安装后运行server.py
***
python server.py
***
浏览器输入
http://127.0.0.1:8000/
进入控制台
![alt text](<屏幕截图 2026-05-19 193650-1.png>)
输入框填入你本地电脑的UVR-5模型的存储路径
![alt text](<屏幕截图 2026-05-19 193658.png>)
在此处可以根据自己的需求依次配置模型，自己控制轮数，完成后点击创建agent
![alt text](<屏幕截图 2026-05-19 193703.png>)
在输入框中填入你想要清洗的音乐文件，随后点击开始即可

完成之后web界面会提示，在目标文件夹中找到最终文件即可。
！！！切记，模型处理流程化未必精细，且目前暂时未实现模型参数控制，对于某些后期强的歌曲可能会出现处理效果不佳等情况！！！
